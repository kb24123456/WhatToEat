# 修复地区按钮无响应问题

## 问题根因
`regions.json` 文件修改后没有被添加到 Xcode 的 "Copy Bundle Resources" 中，导致运行时加载的是旧版本缓存或无法找到文件。

## 解决方案

修改 `RegionManager` 使用更可靠的加载方式，确保能够读取项目目录中的最新文件：

```swift
// 方案：使用 Bundle.main.infoDictionary 获取资源路径
if let url = Bundle.main.url(forResource: "regions", withExtension: "json"),
   let data = try? Data(contentsOf: url) {
    // 解析数据
}
```

或直接在初始化时打印调试信息，帮助确认文件是否正确加载。
