# 在餐厅卡片中添加标签信息（位置调整版）

## 实现思路
1. **位置选择**：将标签信息添加到评分和品类所在的HStack右侧，实现水平排列
2. **样式设计**：复用现有TagView组件或创建类似样式，确保与卡片设计风格一致
3. **布局优化**：使用灵活的布局方式，确保标签、评分和品类能合理共存
4. **响应式设计**：确保在不同屏幕尺寸下都有良好的显示效果

## 实现步骤
1. **修改RestaurantCard组件**：在LibraryView.swift中，修改第204-209行的HStack，添加标签展示区域
2. **标签布局**：在评分和品类的HStack中，使用Spacer分隔，将标签放在右侧
3. **标签样式**：使用类似RestaurantDetailView中的标签样式，或复用现有TagView组件
4. **动态加载**：确保标签信息能根据餐厅的tags数组动态加载
5. **间距调整**：确保标签之间有合理的间距，与其他元素保持协调

## 代码实现要点
1. 修改`RestaurantCard`中评分和品类的HStack：
   ```swift
   HStack(spacing: 12) {
       TagView(text: "⭐️ \(restaurant.rating)", color: AppTheme.Colors.secondary)
       Text(restaurant.type)
           .font(AppTheme.Fonts.footnote)
           .foregroundColor(AppTheme.Colors.textPrimary)
       
       Spacer() // 添加分隔符，将标签推到右侧
       
       if !restaurant.tags.isEmpty {
           // 标签水平排列，使用ScrollView确保在小屏幕上能滚动查看
           ScrollView(.horizontal, showsIndicators: false) {
               HStack(spacing: AppTheme.Spacing.xs) {
                   ForEach(restaurant.tags, id: \.self) {
                       Text("# \($0)")
                           .font(AppTheme.Fonts.footnote)
                           .foregroundColor(AppTheme.Colors.primary)
                           .padding(.horizontal, 8)
                           .padding(.vertical, 3)
                           .background(AppTheme.Colors.primary.opacity(0.1))
                           .cornerRadius(12)
                   }
               }
           }
       }
   }
   ```
2. 确保标签只在有内容时显示
3. 使用水平滚动视图避免标签溢出
4. 应用AppTheme中的颜色和间距规范
5. 使用Spacer将标签推到右侧，实现评分、品类在左，标签在右的布局

## 预期效果
- 标签信息显示在评分和品类的右侧
- 标签采用圆角背景和适当的颜色对比
- 多个标签水平排列，支持滚动
- 与整体卡片设计风格保持一致
- 在不同屏幕尺寸下均有良好的显示效果
