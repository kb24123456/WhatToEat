# 优化卡片展开/收起动画

## 问题
- 收回时没有淡出效果（视图立即消失）
- 动画总时长 300ms 偏慢

## 解决方案

### 1. 修复淡出效果
- **移除 `.transition(...)`**：当 `isDetailPresented` 控制视图显示时，不需要额外的 transition
- **简化动画绑定**：只使用 `.animation(.spring(...), value: isDetailPresented)` 统一控制
- **移除第 100 行的冲突动画**：删除 `value: selectedRestaurant?.id` 的动画

### 2. 缩短动画时长
```swift
// 统一使用 0.15s 响应时间 + 0.7 阻尼
.animation(.spring(response: 0.15, dampingFraction: 0.7), value: isDetailPresented)
```

### 3. 优化关闭时序
- `isPresented = false` → 触发 150ms 淡出动画
- 动画完成后（140ms）自动设置 `selectedRestaurant = nil`

## 代码变更
1. **LibraryView.swift**：
   - 删除 `.transition(...)`
   - 删除第 100 行的冲突动画
   - 保留 `.scaleEffect` + `.opacity` + 统一动画

2. **CenteredDetailCardView.swift**：
   - 延迟时间从 280ms 改为 140ms
   - 背景淡出使用相同的弹簧参数
