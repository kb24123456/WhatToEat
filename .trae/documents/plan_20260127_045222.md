# 问题根因深度分析

## 数据库架构

### SwiftData 模型
```
Restaurant (餐厅)
├── city: String (城市)
├── district: String (地区)  
├── type: String (品类)
├── rating: Double (评分)
├── logs: [VisitLog] (一对多关系)
└── averagePrice: Double (人均消费)

VisitLog (打卡记录)
├── expense: Double (消费金额)
├── peopleCount: Int (人数)
├── date: Date (日期)
└── restaurant: Restaurant? (多对一关系)
```

### 存储位置
- SwiftData 使用 **SQLite** 数据库
- 数据库文件路径：`~/Library/Developer/CoreSimulator/Devices/.../Documents/Default.swiftdata`

## 问题根因

**城市状态被逆地理编码意外覆盖**

### 数据流分析

**正常流程**：
```
LibraryView.selectedCity = "重庆" 
→ 保存到 UserDefaults["UserSelectedCity"]
→ AddRestaurantView 读取 finalCity = "重庆"
→ 保存餐厅 restaurant.city = "重庆"
→ 列表筛选 restaurant.city == "重庆" ✓
```

**问题流程**：
```
LibraryView.selectedCity = "重庆" 
→ 打开 AddRestaurantView
→ 用户选择地址触发逆地理编码
→ placemark.locality 返回其他城市名
→ self.city = 解析出的城市名  ← 覆盖了！
→ finalCity = city (被覆盖的值)
→ 保存餐厅 restaurant.city = 错误城市
→ 列表筛选 restaurant.city != "重庆" ✗
```

## 修复方案

**方案：禁止逆地理编码覆盖用户选择的城市**

在 `AddRestaurantView` 中，如果用户已在 LibraryView 选择城市，逆地理编码只提取地区，不覆盖城市：

```swift
// 逆地理编码时，只更新 district，不更新 city
if let districtName = placemark.subLocality, !districtName.isEmpty {
    self.district = districtName  // ✅ 只更新地区
}
// 移除：if let cityName = placemark.locality { self.city = cityName }
// 城市由 finalCity 兜底逻辑决定
```
