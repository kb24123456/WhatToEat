## 修复添加页面保存卡死问题

### 问题分析
从用户报告和堆栈跟踪来看，应用在添加页面点击保存时卡死，主要原因是：

1. **主线程阻塞**：`saveRestaurant` 方法中的图片保存操作 `ImageManager.shared.saveImage($0)` 直接在主线程执行，导致主线程阻塞
2. **SwiftData 操作不当**：直接在主线程执行 `modelContext.insert(newRestaurant)` 可能导致性能问题
3. **RestaurantCard 视图问题**：`RestaurantCard.body.getter` 方法可能存在性能问题，导致界面卡死

### 修复计划

#### 1. 修复 saveRestaurant 方法
- 将 `saveRestaurant` 方法改为异步方法
- 在后台线程执行图片保存操作
- 确保主线程只负责UI更新

#### 2. 优化 RestaurantCard 视图
- 确保 `RestaurantCard.body.getter` 方法高效执行
- 避免不必要的计算和渲染

### 具体步骤

#### 1. 修改 AddRestaurantView.swift
```swift
// 将 saveRestaurant 方法改为异步方法
private func saveRestaurant() {
    Task {
        // 1. 处理标签字符串转数组
        let tags = tagsInput.split(separator: ",")
            .map { $0.trimmingCharacters(in: .whitespacesAndNewlines) }
            .filter { !$0.isEmpty }
        
        // 2. 在后台线程保存图片
        let filename = await saveImageInBackground()
        
        // 3. 创建餐厅对象
        let newRestaurant = Restaurant(
            name: name,
            type: cuisine,
            district: district,
            rating: rating,
            address: address,
            latitude: latitude,
            longitude: longitude,
            coverPhotoFilename: filename,
            review: review,
            tags: tags,
            averagePrice: 0.0
        )
        
        // 4. 在主线程更新UI
        await MainActor.run {
            modelContext.insert(newRestaurant)
            dismiss()
        }
    }
}

// 在后台保存图片
private func saveImageInBackground() async -> String? {
    guard let image = selectedImage else { return nil }
    return await Task.detached { ImageManager.shared.saveImage(image) }.value
}
```

#### 2. 优化 RestaurantCard 视图
- 确保 `RestaurantCard.body.getter` 方法高效执行
- 避免不必要的计算和渲染

- ✅ 应用在保存时不会卡死
- ✅ 保存操作完成后正常关闭添加页面
