# 修复餐厅保存后列表不显示问题

## 问题分析

发现两个关键问题：

### 1. 城市字段保存后 selectedCity 未同步
- `AddRestaurantView` 保存餐厅时将城市保存到 UserDefaults
- 但 `LibraryView` 的 `selectedCity` 状态没有更新
- 导致 `filteredRestaurants` 中 `restaurant.city == selectedCity` 条件不匹配

### 2. 可能存在城市名称不匹配
- 添加页面保存的 `finalCity` 与 `LibraryView.selectedCity` 可能不一致

## 修复方案

在 LibraryView 中添加 UserDefaults 监听，在保存新餐厅后自动同步城市：

```swift
.onReceive(NotificationCenter.default.publisher(for: .restaurantListShouldRefresh)) { _ in
    // 检查是否需要同步城市
    if let savedCity = UserDefaults.standard.string(forKey: "UserSelectedCity"),
       savedCity != selectedCity {
        selectedCity = savedCity
    }
}
```
