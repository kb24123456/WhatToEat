# 修复地区筛选问题

## 问题分析
`regions.json` 文件虽然在项目目录中存在，但可能没有被正确添加到 Xcode 的 "Copy Bundle Resources" 中，导致 `Bundle.main.url(forResource:)` 找不到文件。

## 解决方案

修改 `RegionManager` 直接从应用 bundle 目录加载文件（而非通过 Bundle API）：

```swift
// 在 main bundle 目录中查找
if let bundlePath = Bundle.main.path(forResource: "regions", ofType: "json"),
   let data = try? Data(contentsOf: URL(fileURLWithPath: bundlePath)),
   let json = try? JSONSerialization.jsonObject(with: data) as? [String: [String]] {
    cityDistricts = json
    return
}
```

或者作为备用方案，从应用 Documents 目录加载。
