### 模拟器闪退排查方案

#### Xcode查看闪退原因的方法

Xcode提供了多种方式查看模拟器闪退原因：

1. **控制台输出**
   - 打开Xcode，点击顶部菜单的"View" → "Debug Area" → "Activate Console"
   - 或使用快捷键`Shift+Cmd+C`
   - 运行应用时，控制台会显示实时日志，包括闪退前的错误信息

2. **设备与模拟器日志**
   - 打开Xcode，点击"Window" → "Devices and Simulators"
   - 选择左侧的模拟器，点击右下角的"View Device Logs"
   - 找到对应时间的崩溃日志，包含详细的堆栈信息

3. **崩溃报告分析**
   - 崩溃后，Xcode会在"Organizer"中显示崩溃报告
   - 点击"Window" → "Organizer" → "Crashes"
   - 选择对应应用和设备，查看崩溃报告
   - 报告包含崩溃类型、堆栈跟踪、线程信息等

#### 完整排查步骤

1. **检查Xcode控制台输出**
   - 运行应用前打开控制台
   - 观察闪退前的最后几条日志，特别注意红色错误信息
   - 查找关键词：`Fatal error`、`Crash`、`Thread 1: EXC_BAD_ACCESS`等

2. **分析设备日志**
   - 打开"Devices and Simulators"
   - 选择闪退的模拟器
   - 点击"View Device Logs"
   - 按时间排序，找到最近的崩溃日志
   - 点击日志查看详细信息，重点关注"Exception Type"和"Stack Trace"

3. **检查常见代码问题**
   - 强制解包：`let value = optionalValue!`
   - 数组越界：访问超过数组长度的索引
   - 内存泄漏：循环引用导致的内存问题
   - 线程冲突：在非主线程更新UI
   - 资源加载失败：图片、文件等资源缺失

4. **尝试基础修复**
   - 清理项目：`Cmd+Shift+K`
   - 清理构建文件夹：`Cmd+Shift+Option+K`
   - 重置模拟器：模拟器菜单"Device" → "Erase All Content and Settings"
   - 重新安装应用

5. **使用断点调试**
   - 在关键代码处设置断点
   - 单步执行，观察变量值变化
   - 特别关注保存按钮相关的代码

#### 常见闪退原因及解决方案

1. **EXC_BAD_ACCESS**：内存访问错误
   - 检查是否有悬垂指针或野指针
   - 避免强制解包Optional值

2. **EXC_CRASH (SIGABRT)**：断言失败或手动终止
   - 检查控制台的断言错误
   - 查看代码中的`fatalError()`调用

3. **NSInternalInconsistencyException**：内部一致性错误
   - 检查UI更新是否在主线程
   - 查看是否违反了API契约

4. **OutOfMemory**：内存不足
   - 检查是否有内存泄漏
   - 优化图片加载和处理

#### 操作建议

1. 先查看Xcode控制台实时输出，获取初步线索
2. 然后查看设备日志，分析完整崩溃报告
3. 根据崩溃类型，针对性检查代码
4. 尝试基础修复措施（清理、重置、重新安装）
5. 如无法解决，可使用断点逐步调试

通过以上步骤，您应该能够定位到模拟器闪退的具体原因并进行修复。
