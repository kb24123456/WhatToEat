# 重构 CheckInView UI 布局与交互体验

## 设计原则
- 延续 AppTheme 奶油系配色、24pt 大圆角
- 弹簧动画 `.spring(response: 0.4, dampingFraction: 0.7)`
- 背景使用 `AppTheme.Colors.background`

## 模块重构

### 1. 顶部用餐类型提示
```swift
// 自动识别当前时间显示用餐类型
Text("正在记录你的 [午餐]")
    .font(AppTheme.Fonts.headline)
    .foregroundColor(AppTheme.Colors.accent)
```

### 2. 拍立得头图区 (PolaroidFrameView)
- **设计**：巨大拍立得相框，白色边框 + 底部宽白边
- **占位图**：插画风格的"馋嘴"图标（`fork.knife.circle.fill`）
- **阴影**：物理投影效果 `shadow(color: .black.opacity(0.15), radius: 20, x: 0, y: 10)`
- **交互**：点击触发 ActionSheet（拍照/相册/删除）

### 3. 消费信息卡片 (ReceiptCardView)
- **设计**：模拟收银小票，底部锯齿边缘
- **人数选择器**：减号/加号按钮，数字居中显示
- **金额输入**：带 ¥ 符号的输入框
- **人均显示**：实时计算，大字号，跳动动画

### 4. 红黑榜 (StickyNoteView)
- **红榜**（左侧）：红色便利贴样式，标题带 👍
- **黑榜**（右侧）：深灰色撕边纸样式，标题带 💣
- **标签化输入**：回车/逗号分隔，自动转化为标签胶囊
- **删除交互**：点击标签 × 号移除

### 5. 心情指数 (MoodSelectorView)
- **Emoji 选项**：😋 满意 | 😐 一般 | 💣 踩雷 | 🤩 惊艳
- **交互反馈**：选中时缩放 + 震动反馈
- **动画**：`.spring(response: 0.3, dampingFraction: 0.6)`

### 6. 评价区 (ReviewEditorView)
- **设计**：极浅奶油色压印效果背景
- **高度限制**：3-6 行，自动换行
- **字体**：AppTheme.Fonts.body

### 7. 保存按钮
- **触感反馈**：UIImpactFeedbackGenerator.medium()
- **成功动画**：Confetti 粒子效果（简化版）
