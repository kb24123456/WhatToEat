# 修复收回时没有淡出效果的动画问题

## 根本原因
当 `onDismiss()` 设置 `selectedRestaurant = nil` 时，LibraryView 的 `onChange` 闭包同时执行 `withAnimation`，触发了新的缩放动画，覆盖了淡出动画，导致视图瞬间消失。

## 解决方案

### 1. LibraryView 添加动画状态标志
```swift
@State private var isAnimatingOut = false

// 修改 onChange 闭包
.onChange(of: isDetailPresented) { _, newValue in
    if !newValue && !isAnimatingOut {
        isAnimatingOut = true
        withAnimation(.spring(response: 0.15, dampingFraction: 0.7)) {
            selectedRestaurant = nil
        }
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.14) {
            isAnimatingOut = false
        }
    }
    isTabBarHidden = newValue
}
```

### 2. CenteredDetailCardView 简化延迟调用
- 移除 `onChange` 中的延迟处理
- 简化 `dismissDetail()` 的实现

## 效果
- 展开：150ms 平滑放大 + 弹簧回弹
- 收回：150ms 缩小 + 完整淡出（不会再被覆盖）
