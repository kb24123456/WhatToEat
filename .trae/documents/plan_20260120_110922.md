# 修改餐厅名称对齐偏移量

## 问题分析
当前餐厅名称的alignmentGuide偏移量为-8pt，需要调整为-20pt，以更好地与封面图圆角以下部分对齐。

## 解决方案
将VStack上的alignmentGuide修饰符值从-8修改为-20。

## 实现步骤

### 1. 修改LibraryView.swift中的alignmentGuide
- **文件**：`LibraryView.swift`
- **位置**：第392行
- **修改内容**：将 `.alignmentGuide(.top) { _ in -8 }` 改为 `.alignmentGuide(.top) { _ in -20 }`

### 2. 验证修改
- 运行构建命令确保没有编译错误
- 检查餐厅名称与封面图的对齐效果

## 预期效果
餐厅名称与封面图圆角以下部分完美对齐，提升卡片整体美观度。
