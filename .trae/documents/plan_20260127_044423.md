# 问题根源分析

## 问题现象
1. 保存餐厅后列表显示餐厅 → 餐厅城市与 selectedCity 匹配
2. 但地区筛选按钮没有任何筛选项 → `currentDistricts` 返回空数组
3. 重新选择重庆后地区筛选正常但餐厅消失 → 餐厅城市与重庆不匹配

## 根本原因

**regions.json 文件没有被正确加载**

`RegionManager` 初始化时尝试三种方式加载文件：
1. `Bundle.main.url(forResource: "regions", withExtension: "json")`
2. `Bundle.main.path(forResource: "regions", ofType: "json", inDirectory: nil)`
3. 从 AppSupport 目录加载

如果所有方式都失败，`cityDistricts` 是空字典 `[:]`

**导致的后果**：
- `getDistricts(for: "重庆")` 返回空数组 → 地区筛选无筛选项
- 列表能显示餐厅 → 因为餐厅是直接存储在 SwiftData 中的

## 修复方案

### 方案1：在 LibraryView 中打印调试信息确认问题

在 `currentDistricts` 中添加日志：
```swift
private var currentDistricts: [String] {
    let districts = RegionManager.shared.getDistricts(for: selectedCity)
    print("currentDistricts: city=\(selectedCity), count=\(districts.count), districts=\(districts)")
    print("RegionManager allCities: \(RegionManager.shared.allCities)")
    return districts
}
```

### 方案2：将 regions.json 添加到 Xcode bundle

在 Xcode 中：
1. 选中项目 → WhatToEat → TARGETS → Build Phases
2. 找到 "Copy Bundle Resources"
3. 点击 "+" 添加 `regions.json`

## 建议

实施 **方案1** 添加调试日志，确认 `regions.json` 是否加载成功。

如果确认是文件未添加到 bundle，实施 **方案2**。
