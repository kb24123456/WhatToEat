# 重构 CheckInView 高级手账质感 UI

## 1. 全局设计规范
- **背景**：AppTheme.Colors.background（极浅米白）
- **卡片阴影**：双层复合阴影 + 0.5pt 白色描边
- **内容宽度**：maxWidth: 400，屏幕居中留边距
- **卡片圆角**：AppTheme.Radius.base (24pt)

## 2. 核心组件重构

### 多图上传卡片
- 添加白色边缘描边
- 标题使用 tracking(1) + 中灰色
- 添加按钮和缩略图阴影优化

### 费用信息卡片（重点重构）
- 三栏横向布局：[人数] | [金额] | [人均]
- 垂直虚线分割
- ¥ 符号缩小加粗，数字使用 monospacedDigit()
- 金额输入添加内阴影压印效果
- 人均数字平滑滚动动画

### 红黑榜卡片
- 红色卡片：极淡红色环境阴影
- 灰色卡片：极淡灰色环境阴影
- 输入框：0.5 透明度背景 + inner shadow 内阴影

### 心情评价区
- 选中态：模糊彩色光晕 + 上浮 -5pt
- 未选中：透明度 0.4 + 黑白效果

### 体验感悟区
- 横格纸/奶油色底纹
- 撕边质感边缘
- 物理纸张投影

## 3. 细节动效
- 所有按钮绑定 UIImpactFeedbackGenerator
- 人均数字数值滚动动画
- 标题 tracking(1) 字间距

## 4. 代码结构
- 新增高级阴影扩展
- 新增卡片容器包装器
- 新增内阴影修饰器
- 重构所有组件 UI
