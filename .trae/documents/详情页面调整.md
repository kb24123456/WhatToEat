## 任务2：添加总消费统计
在 Restaurant 模型中添加计算属性：
```swift
var totalExpense: Double {
    logs.reduce(0.0) { $0 + $1.expense }
}
```

在 statsCardSection 中添加总消费项：
```swift
statsItem(
    icon: "creditcard.fill",
    title: "总消费",
    value: restaurant.totalExpense > 0 ? "¥\(Int(restaurant.totalExpense))" : "暂无数据"
)
```
