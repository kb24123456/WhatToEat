### 二、动态选项功能实现

#### 1. 核心逻辑设计
- **获取现有数据**：使用@Query获取所有餐厅数据，提取唯一的品类和地区
- **动态选项生成**：根据现有数据动态生成品类和地区选项列表
- **混合录入方式**：
  - 当选项列表为空时，仅显示文本输入框
  - 当选项列表不为空时，显示下拉选择器 + 自定义输入选项
  - 支持录入新的品类和地区，自动添加到选项列表

#### 2. 技术实现方案

**数据获取层**：
```swift
@Query private var allRestaurants: [Restaurant]

// 动态生成唯一品类列表
private var categoryOptions: [String] {
    Array(Set(allRestaurants.map { $0.type })).sorted()
}

// 动态生成唯一地区列表
private var districtOptions: [String] {
    Array(Set(allRestaurants.map { $0.district })).sorted()
}
```

**UI交互层**：
- 使用`Picker`组件显示现有选项
- 添加"自定义"选项，点击后显示文本输入框
- 使用`@State`管理当前选择和自定义输入

**状态管理**：
```swift
@State private var selectedCategory: String?
@State private var customCategory: String = ""
@State private var showCustomCategoryInput: Bool = false

// 地区同理
@State private var selectedDistrict: String?
@State private var customDistrict: String = ""
@State private var showCustomDistrictInput: Bool = false
```

#### 3. 保存逻辑更新
- 根据用户选择的方式确定最终的品类和地区值
- 确保新录入的品类和地区正确保存到数据库
