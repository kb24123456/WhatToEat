# 优化淡入淡出与展开收起的时序同步

## 当前问题
动画时序不协调，导致视觉上的不连贯。

## 解决方案

### 统一动画时长为 200ms（更自然的质感）
```swift
.animation(.spring(response: 0.2, dampingFraction: 0.72), value: isDetailPresented)
```

### 简化关闭时序
1. `dismissDetail()`：`isPresented = false` → 触发 200ms 淡出动画
2. 动画完成后（200ms）→ `onDismiss()` → `selectedRestaurant = nil`
3. 移除 `onChange` 中的额外延迟，让 `selectedRestaurant = nil` 在动画完成后执行

### 时序图
```
展开时：
  0ms: isPresented = true → 开始缩放+淡入动画
  200ms: 动画完成，组件全部到位

收回时：
  0ms: isPresented = false → 开始缩放+淡出动画
  200ms: 动画完成，各组件归位
  200ms: selectedRestaurant = nil（此时动画已完成，安全）
```

## 代码变更
1. LibraryView.swift：
   - 动画时长改为 response: 0.2s
   - 简化 onChange 逻辑
   - 调整延迟时间为 0.2s

2. CenteredDetailCardView.swift：
   - 动画时长改为 response: 0.2s
   - 延迟时间改为 0.2s
