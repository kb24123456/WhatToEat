# RestaurantCard 归位动效增强计划

## 目标
将餐厅卡片展开效果从"全屏覆盖"改为"原位拉长"（App Store 活动卡片风格），并为所有信息组件添加 matchedGeometryEffect。

## 实现方案

### 1. RestaurantCard 组件标识优化

为每个需要动画的组件分配唯一的 matchedGeometryEffect ID：

```
封面图:     "coverImage-\(restaurant.id)"
标题:       "title-\(restaurant.id)"
人均消费:   "price-\(restaurant.id)"
地区:       "district-\(restaurant.id)"
评分:       "rating-\(restaurant.id)"
品类:       "type-\(restaurant.id)"
标签:       "tags-\(restaurant.id)"
评价:       "review-\(restaurant.id)"
```.onAppear {
    editedRating = restaurant.rating  // ✅ 直接从内存中的对象读取
}

### 2. RestaurantDetailView 布局重构

- **宽度策略**：使用 GeometryReader 获取屏幕宽度，计算与 RestaurantCard 等宽的展开容器
- **展开方式**：不再使用全屏覆盖，改为在原卡片下方展开
- **ZStack 叠加**：详情内容在列表卡片上方叠加渲染
- **高度动画**：展开时卡片高度平滑增加

### 3. 动画同步策略

- 使用相同的 `@Namespace var animation` 确保所有 ID 匹配
- 展开时使用 `.matchedGeometryEffect` 让组件从原位置平滑过渡
- 保持动画曲线一致：`.spring(response: 0.5, dampingFraction: 0.8)`

### 5. 关键技术点

- 使用 `GeometryReader` 获取卡片位置
- 使用 `CGRect` 计算展开后的目标位置
- 详情页使用 `position` modifier 定位到目标位置
- 保持列表可滚动，展开时详情内容覆盖在列表上方
