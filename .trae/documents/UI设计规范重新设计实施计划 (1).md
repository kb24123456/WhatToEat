# 修复导航栏底部间距问题

## 问题分析
1. 导航栏本身高度设置为60点，使用`.edgesIgnoringSafeArea(.bottom)`忽略底部安全区域
2. 列表内容底部有160点内边距，确保不被导航栏遮挡
3. 中间加号按钮向上偏移28点，视觉重心在60点高度内
4. 可能存在的间距问题：列表底部内边距过大，或导航栏未完全沉底

## 解决方案
1. **调整列表底部内边距**：将LibraryView中列表的`.padding(.bottom, 160)`调整为更合适的值
2. **验证导航栏布局**：确保ZStack对齐和edgesIgnoringSafeArea设置正确
3. **优化视觉效果**：保持导航栏完全沉底，同时确保内容不被遮挡

## 实现步骤
1. 修改LibraryView.swift中listSection的底部内边距，从160调整为90
2. 确保ContentView中的customTabBar保持`.edgesIgnoringSafeArea(.bottom)`设置
3. 验证导航栏是否完全沉底，无额外空间
4. 测试列表内容是否正确显示，不被导航栏遮挡

## 预期效果
- 导航栏完全沉底，底部无额外空间
- 列表内容底部内边距合适，不被导航栏遮挡
- 保持导航栏的设计风格和交互效果
