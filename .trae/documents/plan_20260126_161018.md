# 重构 CheckInView 为多图上传模式

## 1. 更新 VisitLog 模型
```swift
// 将 photoFilename: String? 改为 photoFilenames: [String]
var photoFilenames: [String] = []
```

## 2. 更新 CheckInView 状态变量
```swift
// 旧
@State private var selectedImage: UIImage?

// 新
@State private var selectedImages: [UIImage] = []
```

## 3. 重构拍立得头图区为横向多图布局
```swift
private var multiPhotoSection: some View {
    ScrollView(.horizontal, showsIndicators: false) {
        HStack(spacing: 12) {
            // 添加按钮
            addPhotoButton
            
            // 照片缩略图
            ForEach(selectedImages.indices, id: \.self) { index in
                photoThumbnail(at: index)
            }
        }
    }
    .frame(height: 100)
}
```

## 4. 组件设计
- **添加按钮**：80x80 正方形，浅灰色背景，camera 图标，轻微阴影
- **照片缩略图**：80x80 圆角矩形（AppTheme.Radius.sm），右上角删除按钮
- **删除按钮**：xmark.circle.fill，半透明，点击有缩放动画

## 5. 更新保存逻辑
```swift
private func saveCheckIn() {
    // 保存多张图片，返回文件名数组
    let filenames = selectedImages.compactMap { ImageManager.shared.saveImage($0) }
    log.photoFilenames = filenames
}
```

## 6. 更新编辑回显逻辑
```swift
private func loadEditingLog(_ log: VisitLog) {
    // 加载多张照片
    selectedImages = log.photoFilenames.compactMap { filename in
        ImageManager.shared.loadImage(filename: filename)
    }
}
```

## 7. 删除旧照片同步
当删除照片或编辑覆盖时，同步删除磁盘上的旧文件。
