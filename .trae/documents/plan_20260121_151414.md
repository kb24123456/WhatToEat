# 动画规范制定计划

## 1. 性能优化规范

### 1.1 动画载体规则
- **规则说明**：强制优先使用Core Animation（CALayer）实现动画，优先操作transform/opacity/position等轻量级属性，禁止动画frame/bounds
- **执行要求**：所有动画必须使用CALayer实现，禁止使用UIView.animate
- **代码示例**：正例+反例，标注关键优化点

### 1.2 主线程隔离规则
- **规则说明**：动画所有回调/进度监听中，禁止执行耗时操作，耗时逻辑必须迁移至子线程，仅UI更新回主线程
- **执行要求**：使用GCD或OperationQueue实现主线程隔离
- **代码示例**：正例+反例，标注关键优化点

### 1.3 渲染优化规则
- **规则说明**：针对圆角+阴影视图，强制设置shadowPath避免离屏渲染，规范masksToBounds的使用场景；动画所用图片必须实现子线程预解码，标记不透明视图的opaque属性为true
- **执行要求**：所有圆角+阴影视图必须设置shadowPath，图片必须预解码
- **代码示例**：正例+反例，标注关键优化点

### 1.4 批量动画规则
- **规则说明**：餐厅卡片/列表cell等批量动画必须分批执行，明确单批次最大数量、批次延迟时间，分散GPU渲染压力
- **执行要求**：单批次最多10个动画，批次间延迟0.05秒
- **代码示例**：正例+反例，标注关键优化点

### 1.5 动画资源管理规则
- **规则说明**：规范CALayer动画、SpriteKit粒子动画的创建/销毁逻辑，避免内存泄漏；超复杂动画明确SpriteKit替代Core Animation的使用场景
- **执行要求**：动画完成后必须清理资源，复杂粒子动画使用SpriteKit
- **代码示例**：正例+反例，标注关键优化点

## 2. 视觉/交互规范

### 2.1 统一动画基础参数
- **规则说明**：按“基础动画、中等动画、复杂动画”分类，明确统一的动画时长、缓动曲线
- **执行要求**：所有组件必须使用规范内的参数，禁止硬编码
- **参数表**：明确不同类型动画的时长、缓动曲线

### 2.2 组件动效标准化
- **搜索类**：餐厅搜索框（聚焦/失焦/输入反馈）
- **筛选类**：筛选开关按钮、二级筛选菜单（展开/收起）、筛选标签（选中/取消）
- **弹窗类**：提示弹窗、确认弹窗、加载弹窗（渐入/渐出、展示/隐藏）
- **导航类**：顶部导航栏（页面转场、标题切换）、底部TabBar（切换、选中反馈）
- **其他**：蒙层（显示/隐藏）、空页面/错误页面（展示/消失）

### 2.3 核心交互动效规范
- **物理动效**：Physics-Based Animation / 自然动效（Natural Motion）
- **归位动效**：Return Animation / Origin-Based Transition / 触发点复位动效
- **微交互**：Microinteractions / 表现力动效（Expressive Animation） / 多汁动画（Juicy Animation）
- **层级菜单**：Hierarchical Capsule Menu / 嵌套上下文菜单（Nested Context Menu）
