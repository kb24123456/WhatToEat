# RestaurantDetailView 二次编辑交互优化

## 任务1：地区与品类 - 胶囊选择器

将 infoSection 的 TextField 改为弹出胶囊选择器：

```swift
// 品类选择器 - 使用预设品类
Menu {
    ForEach(presetCategories, id: \.self) { category in
        Button(category) { selectedCategory = category }
    }
} label: {
    CapsuleSelectionButton(
        title: "品类",
        selectedValue: $editedCategory,
        options: CategoryManager.shared.getPresetCategories()
    )
}

// 地区选择器 - 动态获取
Menu {
    ForEach(availableDistricts, id: \.self) { district in
        Button(district) { editedDistrict = district }
    }
} label: {
    CapsuleSelectionButton(
        title: "地区",
        selectedValue: $editedDistrict,
        options: availableDistricts
    )
}
```
