# 修改餐厅卡片UI布局

## 问题分析
1. 餐厅卡片当前使用了阴影效果：`.shadow(color: Color.black.opacity(0.04), radius: 10, x: 0, y: 4)`
2. 卡片内部使用了`.padding(AppTheme.Spacing.card)`设置统一间距，限制了信息与卡片边缘的距离
3. 需要取消阴影效果并调整内部间距，让卡片内容更紧凑

## 解决方案
1. 移除餐厅卡片的阴影修饰符
2. 调整卡片内部padding，特别是上下边缘的间距
3. 保持卡片的其他设计元素不变

## 实现步骤
1. 修改LibraryView.swift中的RestaurantCard实现
2. 移除阴影修饰符：`.shadow(color: Color.black.opacity(0.04), radius: 10, x: 0, y: 4)`
3. 调整卡片内部padding，将统一的`.padding(AppTheme.Spacing.card)`修改为只设置水平padding，取消上下padding
4. 运行项目验证效果，确保卡片无阴影且内部信息与上下边缘无间距限制

## 预期效果
- 餐厅卡片无阴影效果
- 卡片内部信息与上下边缘无间距限制
- 保持卡片左右边缘的适当间距
- 卡片内容更紧凑，视觉上更简洁

## 技术实现
1. 修改LibraryView.swift文件
2. 移除阴影修饰符
3. 调整padding设置，从统一padding改为只设置水平padding
4. 保持代码结构不变
5. 确保编译通过
6. 验证修改效果
