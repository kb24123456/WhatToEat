# 排查餐厅保存问题

## 问题分析

通过代码审查发现以下关键点：

### 1. AddRestaurantView 保存逻辑 ✅
城市字段已正确保存（`AddRestaurantView.swift` 第 412-428 行）：
- `finalCity` 正确设置
- 保存到 `UserDefaults.standard.set(finalCity, forKey: "UserSelectedCity")`
- Restaurant 对象创建时传入 `city: finalCity`

### 2. LibraryView 筛选逻辑 ✅
`filteredRestaurants` 依赖 `restaurant.city == selectedCity`（第 366 行）

### 3. 潜在问题

**SwiftData @Query 刷新问题**：
- `@Query private var restaurants: [Restaurant]` 在添加新餐厅后可能不会自动刷新
- 需要显式触发上下文保存后的刷新机制

## 修复方案

### 方案 A：在 LibraryView 中添加刷新机制

在 LibraryView 的 `.onChange(of: isDetailPresented)` 后添加：
```swift
.onReceive(NotificationCenter.default.publisher(for: .refreshRestaurantList)) { _ in
    // 强制刷新 Query
}
```

### 方案 B：使用 @Query 的自动刷新

检查 `@Query` 配置是否需要添加 `animation: .default` 来自动响应数据变化

### 方案 C：在添加页面关闭后触发列表刷新

在 AddRestaurantView 保存成功后发送通知，让 LibraryView 刷新列表

## 建议实施

实施 **方案 C**：添加通知机制确保列表刷新
