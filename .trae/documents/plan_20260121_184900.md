# 重新设计headerSection方案

## 1. 问题分析
- 当前headerSection只包含一个右上角的导入按钮
- 标题和搜索框是独立的视图
- 需要整合标题、搜索框和地图图标到headerSection
- 需要删除导入功能按钮
- 需要将筛选按钮上移

## 2. 解决方案
- 重新设计headerSection，整合标题、搜索框和地图图标
- 删除独立的titleSection
- 调整VStack布局，将filterBarSection上移
- 保持整体布局的美观和一致性

## 3. 实现步骤

### 步骤1：重新设计headerSection
- 删除当前的导入按钮
- 添加标题"吃啥呢"
- 整合搜索框
- 添加地图图标按钮
- 保持原有的搜索框样式和动画效果

### 步骤2：删除独立的titleSection
- 删除titleSection变量
- 将标题功能整合到headerSection中

### 步骤3：调整VStack布局
- 移除titleSection的调用
- 保持filterBarSection的位置不变（自然上移）

## 4. 设计细节

### headerSection布局
```swift
HStack(spacing: AppTheme.Spacing.md) {
    // 1. 标题"吃啥呢"
    Text("吃啥呢")
        .font(AppTheme.Fonts.largeTitle)
        .fontWeight(.bold)
        .foregroundColor(AppTheme.Colors.textPrimary)
    
    // 2. 搜索框（占据剩余空间）
    HStack {
        Image(systemName: "magnifyingglass").foregroundColor(.gray)
        TextField("搜索餐厅名称、菜系...", text: $searchText)
            .font(AppTheme.Fonts.body)
            .focused($isSearchFocused)
    }
    .padding(AppTheme.Spacing.md)
    .background(AppTheme.Colors.card)
    .cornerRadius(AppTheme.Radius.base)
    .overlay(
        RoundedRectangle(cornerRadius: AppTheme.Radius.base)
            .stroke(isSearchFocused ? AppTheme.Colors.accent : Color.clear, lineWidth: 1.5)
    )
    .shadow(
        color: isSearchFocused ? AppTheme.Colors.accent.opacity(0.1) : Color.black.opacity(0.04),
        radius: isSearchFocused ? 15 : 8,
        x: 0,
        y: isSearchFocused ? 8 : 2
    )
    .scaleEffect(isSearchFocused ? 1.02 : 1.0)
    .animation(.interactiveSpring(response: 0.3, dampingFraction: 0.7, blendDuration: 0.2), value: isSearchFocused)
    
    // 3. 地图图标按钮
    Button(action: { 
        // 暂不添加功能
    }) {
        Image(systemName: "map")
            .font(AppTheme.Fonts.title3)
            .foregroundColor(AppTheme.Colors.textPrimary)
    }
    .buttonStyle(.plain)
}
.padding(AppTheme.Spacing.lg)
.background(AppTheme.Colors.background)
```
