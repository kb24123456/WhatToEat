# 添加初始数据计划

## 目标
在应用首次启动时添加一些示例餐厅数据，丰富用户体验。

## 实现步骤

1. **修改 WhatToEatApp.swift**
   - 在 ModelContainer 初始化后添加初始数据检查逻辑
   - 使用 ModelContext 查询现有餐厅数据
   - 如果没有数据，则插入示例餐厅

2. **创建示例数据**
   - 准备 3-5 个不同类型的示例餐厅
   - 包含完整的餐厅信息（名称、类型、评分、地址等）
   - 确保数据结构符合 Restaurant 模型要求

3. **实现数据插入逻辑**
   - 使用 ModelContext.insert() 方法插入示例数据
   - 确保数据只在首次启动时添加
   - 处理可能的错误情况

## 代码实现要点

- 在 sharedModelContainer 初始化后的 do-catch 块中添加初始数据逻辑
- 使用 try! modelContext.fetch(FetchDescriptor<Restaurant>()) 检查现有数据
- 准备示例餐厅数组，包含不同类型和评分的餐厅
- 使用 for 循环插入所有示例数据

## 预期效果
- 首次启动应用时，自动添加 3-5 个示例餐厅
- 已有数据时，不会重复添加
- 用户可以在"食库"页面看到初始数据
- 不影响应用的正常运行和数据管理功能
