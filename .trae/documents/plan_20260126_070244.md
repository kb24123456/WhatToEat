# 分离动画时序

## 目标效果
1. **组件动画（matchedGeometryEffect）**：150ms，先完成
2. **卡片缩放**：200ms，后完成
3. **背景淡入/淡出**：220ms，最后完成

## 实现方案

### 1. 组件动画（150ms）- 先完成
为 `matchedGeometryEffect` 元素添加独立的快速动画：
```swift
.matchedGeometryEffect(id: "coverImage-\(restaurant.id)", in: animation)
.animation(.spring(response: 0.15, dampingFraction: 0.72), value: isDetailPresented)
```

### 2. 卡片缩放（200ms）- 后完成
保持现有的卡片缩放动画时长为 200ms。

### 3. 背景淡入/淡出（220ms）- 最后完成
背景使用最长的动画时长 220ms。

### 4. zIndex 确保层级
为关键元素添加 `zIndex(1)`，确保组件在卡片缩放时已"凝固"在正确位置：
```swift
VStack {
    coverImageSection.zIndex(1)
    headerSection.zIndex(1)
    ...
}
```

### 时序图
```
展开时：
  0ms: 开始所有动画
  150ms: 组件动画完成（封面图、标题、评分等归位）
  200ms: 卡片缩放完成
  220ms: 背景淡入完成

收回时：
  0ms: 开始所有动画
  150ms: 组件动画完成（从卡片分离）
  200ms: 卡片缩放完成
  220ms: 背景淡出完成
```
