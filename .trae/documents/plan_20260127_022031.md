# 餐厅详情页问题修复

## 任务1：添加评星组件
在 statsCardSection 中添加第4个 statsItem 显示评分：
- 使用 5 星显示当前评分
- 点击可展开评分选择器（1-5星）
- 支持二次打分并保存

```swift
// 在人均消费后添加
statsItem(
    icon: "star.fill",
    title: "我的评分",
    value: String(format: "%.1f", restaurant.rating)
)

// 点击弹出评分选择器 Menu
Menu {
    ForEach(1...5, id: \.self) { star in
        Button {
            restaurant.rating = Double(star)
            let generator = UINotificationFeedbackGenerator()
            generator.notificationOccurred(.success)
        } label: {
            HStack {
                ForEach(1...5, id: \.self) { s in
                    Image(systemName: s <= star ? "star.fill" : "star")
                        .foregroundColor(.yellow)
                }
                Text("\(star) 星")
            }
        }
    }
} label: {
    // 可点击的星星组件
}
```
