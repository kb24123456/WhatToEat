## 在AppTheme中添加卡片尺寸规范实施计划

### 问题分析
当前项目中卡片尺寸直接定义在组件内部，缺少统一的设计规范管理。需要将卡片尺寸规范添加到AppTheme中，实现统一管理和复用。

### 解决方案
1. **在AppTheme中添加卡片尺寸规范**：创建Cards结构体，定义各种卡片尺寸常量
2. **修改组件使用规范**：更新RestaurantCard组件，使用AppTheme.Cards中的常量
3. **确保代码兼容性**：确保修改后的代码能够正常编译和运行

### 具体修改步骤

#### 1. 在AppTheme中添加卡片尺寸规范
- 打开AppTheme.swift文件
- 在合适位置添加Cards结构体，定义餐厅卡片的尺寸常量
- 包含封面图宽度、高度、比例等属性

#### 2. 修改RestaurantCard组件
- 打开LibraryView.swift文件
- 定位到RestaurantCard结构体
- 移除内部定义的coverSize常量
- 使用AppTheme.Cards中的常量替代

### 预期效果
- 卡片尺寸实现统一管理，便于后续修改和维护
- 确保应用中所有卡片使用相同的尺寸规范
- 提高代码的可复用性和一致性
- 便于实现响应式设计

### 代码示例

**1. AppTheme.swift中添加Cards结构体**
```swift
// MARK: - 6. 卡片尺寸规范
struct Cards {
    // 餐厅卡片
    static let restaurantCoverWidth: CGFloat = 100
    static let restaurantCoverHeight: CGFloat = 178
    static let restaurantCoverRatio: CGFloat = 9/16
}
```

**2. RestaurantCard组件中使用规范**
```swift
// 移除内部定义
// private let coverSize = CGSize(width: 100, height: 178)

// 使用AppTheme.Cards中的常量
.frame(width: AppTheme.Cards.restaurantCoverWidth,
       height: AppTheme.Cards.restaurantCoverHeight)
```

### 注意事项
- 确保卡片尺寸常量的命名清晰，便于理解和使用
- 考虑添加注释，说明每个尺寸的用途和设计意图
- 确保修改后的代码能够正常编译和运行
- 考虑后续可能的响应式设计需求，为未来扩展预留空间
