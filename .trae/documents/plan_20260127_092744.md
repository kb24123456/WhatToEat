# RestaurantDetailView 重构计划

## 1. 顶部布局与材质重构

### 1.1 封面图
- 高度改为 320pt
- 顶部忽略安全区域 `.ignoresSafeArea(.top)`
- 底部应用 32pt 大圆角

### 1.2 毛玻璃关闭钮
- 直径 32pt 圆形
- 背景 `.ultraThinMaterial`
- 微弱投影 `shadow(radius: 4, x: 0, y: 2)`

### 1.3 悬浮红纽扣 (FAB)
- 胶囊形按钮
- 渐变背景从左上到右下
- 红色弥散阴影 `color: .red.opacity(0.3), radius: 12, y: 8`

## 2. 级联阻尼滑出动效

### 2.1 动画状态
```swift
@State private var animateContent = false
```

### 2.2 触发时机
```swift
.onAppear {
    animateContent = false
    withAnimation(.spring(response: 0.6, dampingFraction: 0.8)) {
        animateContent = true
    }
}
```

### 2.3 模块级联延迟
| 模块 | 延迟 |
|------|------|
| 标题与基础信息 | 0.05s |
| 统计数据卡片 | 0.10s |
| 地址与路线模块 | 0.15s |
| 我的印象模块 | 0.20s |
| 打卡记录列表 | 0.25s |

### 2.4 位移动画
```swift
.offset(y: animateContent ? 0 : 40)
.opacity(animateContent ? 1 : 0)
.animation(.spring(response: 0.6, dampingFraction: 0.8).delay(delay), value: animateContent)
```

## 3. 细节美化

### 3.1 幽灵删除按钮
```swift
.background(Color.clear)
.overlay(
    Capsule().stroke(Color.gray, lineWidth: 1)
)
.foregroundColor(.red)
```

### 3.2 编辑图标颜色
```swift
.foregroundColor(Color.gray.opacity(0.3))
```

### 3.3 卡片边缘描边
```swift
.overlay(
    RoundedRectangle(cornerRadius: 12)
        .stroke(Color.white.opacity(0.5), lineWidth: 0.5)
)
```
