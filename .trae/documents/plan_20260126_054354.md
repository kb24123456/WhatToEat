# App Store 风格卡片展开动画

## 目标
实现点击餐厅卡片后，从原位平滑放大展开到详情卡片，带有弹簧动画效果。

## 实现方案

### 1. 修改 LibraryView 动画逻辑
- 使用 `scaleEffect` + `opacity` 实现缩放转场
- 背景遮罩使用 `opacity` 淡入淡出
- 整个动画使用弹簧曲线 `.spring(response: 0.5, dampingFraction: 0.75)`

### 2. 优化 CenteredDetailCardView 动画
- 卡片默认 `scaleEffect(0.9)` + `opacity(0)`
- 展开时平滑过渡到 `scaleEffect(1)` + `opacity(1)`
- 使用 matchedGeometryEffect 确保元素从原位过渡

### 3. 动画时序
- 背景遮罩：0.0 → 0.5（与卡片缩放同步）
- 卡片缩放：0.9 → 1.0（弹簧回弹效果）
- 卡片透明度：0 → 1

### 4. 关闭动画
- 点击背景关闭时，卡片缩小回原位
- 背景同步淡出
