# 修复新餐厅地区信息储存问题

## 问题分析

### 发现的问题

在 `AddRestaurantView` 第 437-441 行，逆地理编码只更新了经纬度，没有更新 `district` 和 `city`：

```swift
// 现有代码（有问题）
let placemarks = try await geocoder.geocodeAddressString(address)
if let placemark = placemarks.first, let location = placemark.location {
    finalLatitude = location.coordinate.latitude
    finalLongitude = location.coordinate.longitude
    // ❌ 没有更新 district 和 city
}
```

### 数据流验证

**保存逻辑正确**：
- ✅ `finalCity` 有兜底逻辑（UserDefaults → 定位 → 默认重庆）
- ✅ `district` 变量从地图选择或表单输入获取
- ✅ 验证要求 `district` 不为空

**筛选逻辑正确**：
- ✅ `filteredRestaurants` 按 `city` 和 `district` 筛选

**问题点**：
当用户手动输入地址触发逆地理编码时，解析出的 `subLocality`（区）没有被保存到 `district` 变量。

## 修复方案

在逆地理编码成功后，同时更新 `district` 和 `city`：

```swift
let placemarks = try await geocoder.geocodeAddressString(address)
if let placemark = placemarks.first {
    if let location = placemark.location {
        finalLatitude = location.coordinate.latitude
        finalLongitude = location.coordinate.longitude
    }
    // 新增：更新地区和城市
    if let districtName = placemark.subLocality, !districtName.isEmpty {
        self.district = districtName
    }
    if let cityName = placemark.locality, !cityName.isEmpty {
        self.city = cityName
    }
}
```
