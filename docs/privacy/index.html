WhatToEat 隐私政策

本政策用于说明 WhatToEat 在提供餐厅记录、打卡、消费、地图与会员相关功能时，可能会处理哪些信息、如何使用这些信息，以及你可以如何控制自己的数据。

适用于 WhatToEat iOS App 最后更新：2026 年 3 月 8 日

1. 我们会处理哪些信息

WhatToEat 主要处理你主动在 App 中创建或维护的数据，包括餐厅名称、位置、标签、品类、打卡记录、消费金额、备注、图片，以及由这些数据生成的地图与统计信息。 当你主动使用 Apple ID 登录、Prime 购买恢复、iCloud 同步、定位、相机或相册等功能时，App 还可能访问相关的账户状态、权限状态与功能所必需的数据。

2. 我们如何使用这些信息

这些信息仅用于向你提供餐厅记录、打卡整理、地图展示、消费统计、标签管理、会员能力、数据导入导出、账户切换与安全验证等功能。 对于你未主动使用的功能，WhatToEat 不会无理由访问或上传无关信息。

3. 同步、存储与备份

默认情况下，WhatToEat 的核心记录数据保存在你的本地设备中。如果你在 App 内开启 iCloud 同步，相关数据会通过 Apple 提供的 iCloud/CloudKit 基础设施在你的设备之间同步。 你也可以使用导出能力将餐厅数据导出为文件，以便做额外备份与迁移。

4. 权限与第三方服务

WhatToEat 可能会请求定位、相机、相册等权限，用于帮助你记录餐厅位置、拍摄或选择照片。你可以随时在系统设置中关闭这些权限。 当你主动使用 AI 文案、运势等外部服务时，App 可能会将该次操作所必需的数据发送给相关服务提供方，以获得对应结果。

5. 你的控制权

你可以在 App 内自行新增、修改、删除餐厅与打卡内容，关闭定位或 iCloud 同步，退出 Apple ID 账户，或删除当前 Apple ID 账户关联。 删除账户关联仅会移除 Apple ID 登录状态与本地账户关联信息，不会自动清除你已经保存在本机的餐厅、打卡、消费与标签数据。

6. 联系我们

如你对本隐私政策或数据处理方式有疑问，可通过支持页中提供的联系方式与我联系。 你也可以直接发送邮件至 357831193@qq.com。
