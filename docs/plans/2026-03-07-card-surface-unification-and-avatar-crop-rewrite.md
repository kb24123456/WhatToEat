# 卡片颜色统一与头像裁剪器重写计划

## 目标
- 将个人页相关所有卡片组件在深色模式下统一为与数据卡片相同的卡片底色、描边和阴影语义。
- 重写头像裁剪流程，改为固定圆形取景框、图片在框内拖拽缩放的原生交互，消除双圆框和取景框跟随移动的问题。

## 范围
- `WhatToEat/AppTheme.swift`
- `WhatToEat/ProfileView.swift`
- `WhatToEat/ExpandableCard.swift`

## 步骤
1. 抽取深色数据卡片使用的统一卡片 surface / stroke / shadow token。
2. 将头像名片、收缩态入口卡、功能设置展开卡、数据卡和时间线卡统一切到这套 token。
3. 删除当前头像裁剪页的反向遮罩方案，改为固定圆形舞台 + 自定义顶部按钮条。
4. 保留相册确认后进入裁剪页的流程，仅替换裁剪视图内部实现与导出逻辑。
5. 进行构建验证；若仍受本机 `actool/CoreSimulator` 环境影响，明确记录。

## 风险
- 颜色统一若直接改全局语义色会影响项目其他页面，因此只新增 Profile 场景专用 token。
- 裁剪器重写需确保导出坐标与屏幕上的缩放/偏移一致，否则会出现保存结果与预览不一致。
