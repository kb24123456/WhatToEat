# 在搜索框左上方添加标题"吃啥呢"

## 1. 问题分析
- 当前布局中，headerSection只包含一个右上角的导入按钮
- 搜索框直接位于headerSection下方，缺少标题
- 需要在搜索框左上方添加标题"吃啥呢"

## 2. 解决方案
- 在VStack布局中，在searchBarSection之前添加一个标题视图
- 保持标题的样式与现有设计风格一致
- 确保标题左对齐，与搜索框的左边距保持一致

## 3. 实现步骤
1. 创建一个新的标题视图变量
2. 在VStack中，将标题视图放在searchBarSection之前
3. 设计标题样式，使用AppTheme中的字体和颜色
4. 确保标题与搜索框的间距合理

## 4. 修改代码

### 步骤1：创建标题视图变量
在headerSection和searchBarSection之间添加：

```swift
// MARK: - 标题
private var titleSection: some View {
    Text("吃啥呢")
        .font(AppTheme.Fonts.largeTitle) // 大标题字体
        .fontWeight(.bold)
        .foregroundColor(AppTheme.Colors.textPrimary)
        .padding(.leading, AppTheme.Spacing.lg) // 与搜索框左边距保持一致
        .padding(.top, AppTheme.Spacing.md)
        .padding(.bottom, AppTheme.Spacing.sm)
}
```

### 步骤2：将标题视图添加到VStack中
修改VStack的子视图顺序：

```swift
VStack(alignment: .leading, spacing: 0) {
    headerSection
    titleSection // 添加标题视图
    searchBarSection
    filterBarSection
    listSection
}
```

## 5. 样式设计
- **字体**：使用AppTheme.Fonts.largeTitle，与现有设计风格一致
- **颜色**：使用AppTheme.Colors.textPrimary，保持与其他文本一致
- **间距**：左边距与搜索框保持16pt，顶部12pt，底部8pt
- **对齐**：左对齐，与搜索框和筛选按钮保持一致

## 6. 预期效果
- 在搜索框左上方显示"吃啥呢"大标题
- 标题与搜索框保持合适间距
- 整体布局保持一致的左对齐风格
- 符合AppTheme的设计规范

## 7. 验证方法
- 运行项目构建，确保无编译错误
- 检查界面效果，确认标题显示正确
- 验证标题样式和间距符合设计规范
