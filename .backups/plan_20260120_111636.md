# 基于字体属性的餐厅名称对齐优化

## 问题分析
当前餐厅名称使用固定偏移量(-20pt)对齐，无法精确适应不同字体和设备。需要基于字体的capHeight和ascender属性计算动态偏移量，实现与封面图上边框的视觉对齐。

## 解决方案
使用SwiftUI的GeometryReader和字体测量技术，获取餐厅名称字体的精确尺寸，计算基于capHeight和ascender的动态偏移量，确保与封面图上边框视觉对齐。

## 实现步骤

### 1. 设计字体测量方案
- **创建字体测量函数**：使用GeometryReader和Text测量title3字体的capHeight和ascender
- **计算偏移量**：
  ```
  偏移量 = 封面图圆角大小 - (ascender - capHeight) - VStack顶部内边距
  ```

### 2. 实现动态alignmentGuide
- **添加GeometryReader**：在RestaurantCard中添加字体测量逻辑
- **使用PreferenceKey**：传递测量结果到alignmentGuide
- **动态计算偏移量**：在alignmentGuide中使用测量的字体属性

### 3. 移除固定偏移量
- 删除当前固定的`.alignmentGuide(.top) { _ in -20 }`
- 替换为基于字体属性的动态计算

### 4. 验证对齐效果
- 运行应用查看视觉效果
- 确保在不同设备和字体大小下都保持对齐

## 代码实现示例

### 1. 添加PreferenceKey
```swift
struct FontMetricsKey: PreferenceKey {
    static var defaultValue: (capHeight: CGFloat, ascender: CGFloat) = (0, 0)
    static func reduce(value: inout (capHeight: CGFloat, ascender: CGFloat), nextValue: () -> (capHeight: CGFloat, ascender: CGFloat)) {
        value = nextValue()
    }
}
```

### 2. 实现字体测量
```swift
// 在RestaurantCard中添加
@State private var fontMetrics: (capHeight: CGFloat, ascender: CGFloat) = (0, 0)

// 在VStack前添加隐藏的测量文本
GeometryReader {geometry in
    Text("X") // 使用大写字母测量capHeight
        .font(AppTheme.Fonts.title3)
        .bold()
        .hidden()
        .baselineOffset(0)
        .preference(key: FontMetricsKey.self, value: (
            capHeight: geometry.size.height,
            ascender: geometry.size.height + 4 // 基于实际测量调整
        ))
}
.frame(height: 0)
.onPreferenceChange(FontMetricsKey.self) { metrics in
    self.fontMetrics = metrics
}
```

### 3. 动态alignmentGuide
```swift
.alignmentGuide(.top) { _ in
    // 计算动态偏移量：封面图圆角(16pt) - 字体顶部留白 - 内边距(8pt)
    let fontTopSpacing = fontMetrics.ascender - fontMetrics.capHeight
    let offset = AppTheme.Radius.image - fontTopSpacing - AppTheme.Spacing.sm
    return -offset
}
```

## 预期效果
餐厅名称与封面图上边框实现精确视觉对齐，自适应不同字体和设备，提升设计的专业度和一致性。
