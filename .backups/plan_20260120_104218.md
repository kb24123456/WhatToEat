# 使用 alignmentGuide 实现餐厅名称与封面图精确对齐

## 问题分析
当前餐厅名称与封面图视觉不对齐的主要原因是：
1. 字体自身的 ascent 空间（文字上方的默认留白）
2. VStack 存在默认的顶部边距
3. Image 和 Text 视图的对齐基准不同
4. SwiftUI 基于锚点的布局系统差异

## 解决方案
使用 SwiftUI 的 `alignmentGuide` 修饰符自定义 VStack 的顶部对齐，确保餐厅名称与封面图上边缘视觉齐平。

## 实现步骤

### 1. 修改 RestaurantCard 中的 VStack 布局
- **文件**：`LibraryView.swift`
- **位置**：第343行的 `VStack` 元素
- **修改内容**：添加 `.alignmentGuide(.top) { _ in -8 }` 修饰符

### 2. 移除现有对齐调整
- 删除餐厅名称 Text 元素上的 `.padding(.top, -3)` 修饰符
- 确保 HStack 对齐方式正确设置为 `.top`

### 3. 验证对齐效果
- 运行应用查看视觉效果
- 确保在不同设备上都保持对齐

## 代码实现

### 修改前
```swift
VStack(alignment: .leading, spacing: 8) {
    HStack {
        Text(restaurant.name)
            .font(AppTheme.Fonts.title3)
            .bold()
            .lineLimit(1)
            .foregroundColor(AppTheme.Colors.textPrimary)
            .padding(.top, -3) // 向上调整3pt，与封面图上边缘齐平
        // ...
    }
    // ...
}
```

### 修改后
```swift
VStack(alignment: .leading, spacing: 8) {
    HStack {
        Text(restaurant.name)
            .font(AppTheme.Fonts.title3)
            .bold()
            .lineLimit(1)
            .foregroundColor(AppTheme.Colors.textPrimary)
        // ...
    }
    // ...
}
.alignmentGuide(.top) { _ in -8 } // 自定义顶部对齐，向上偏移8pt
```

## 预期效果
餐厅名称与封面图上边缘视觉齐平，并且能够适应不同设备和字体大小的变化，保持一致的视觉效果。
