## 问题分析
从代码和崩溃信息来看，应用在选择排序选项后崩溃的原因是：

1. 当用户选择排序选项时，`activeSort`状态更新
2. 状态更新触发`filteredAndSortedRestaurants`计算属性重新计算
3. 排序逻辑中，特别是`.distance`排序，使用了`locationManager.userLocation`
4. 这导致SwiftData尝试重新执行`@Query`，但遇到了反射元数据问题
5. 应用崩溃

## 解决方案

### 1. 优化filteredAndSortedRestaurants计算属性
- 减少不必要的计算，避免频繁触发SwiftData查询
- 确保排序逻辑不会导致SwiftData反射元数据问题
- 优化`.distance`排序的逻辑，避免在计算属性中进行复杂的位置计算

### 2. 使用@State变量缓存排序结果
- 将计算属性改为使用@State变量缓存结果
- 只有当依赖的状态变化时才重新计算
- 减少SwiftData查询的执行频率

### 3. 优化排序逻辑
- 确保排序逻辑在各种情况下都能正常工作
- 添加更详细的错误处理
- 避免在排序逻辑中进行可能导致问题的操作

## 代码修改计划

### LibraryView.swift

1. **添加@State变量缓存排序结果**
```swift
// 在现有状态变量后添加
@State private var sortedRestaurants: [Restaurant] = []
```

2. **添加onChange修饰符监听依赖状态变化**
```swift
.onChange(of: [searchText, selectedCuisine, selectedDistrict, selectedCity, activeSort, restaurants]) { 
    // 当任何依赖状态变化时，重新计算排序结果
    sortedRestaurants = filteredAndSortedRestaurantsInternal
}
```

3. **将filteredAndSortedRestaurants改为内部函数**
```swift
// 内部函数，用于计算过滤和排序结果
private func filteredAndSortedRestaurantsInternal() -> [Restaurant] {
    var filtered = restaurants.filter { restaurant in
        if searchText.isEmpty { return true }
        let s = searchText.lowercased()
        return restaurant.name.lowercased().contains(s) ||
               restaurant.type.lowercased().contains(s) ||
               restaurant.address.lowercased().contains(s)
    }
    if let c = selectedCuisine { filtered = filtered.filter { $0.type == c } }
    if let d = selectedDistrict { filtered = filtered.filter { $0.district == d } }
    if let city = selectedCity { filtered = filtered.filter { $0.city == city } }
    
    return filtered.sorted { lhs, rhs in
        switch activeSort {
        case .rating: return lhs.rating > rhs.rating
        case .distance:
            guard let userLoc = locationManager.userLocation else { return lhs.rating > rhs.rating } // 优化：当位置不可用时，使用评分排序
            let lLoc = CLLocation(latitude: lhs.latitude, longitude: lhs.longitude)
            let rLoc = CLLocation(latitude: rhs.latitude, longitude: rhs.longitude)
            return userLoc.distance(from: lLoc) < userLoc.distance(from: rLoc)
        case .name: return lhs.name < rhs.name
        default: return true
        }
    }
}
```

4. **修改视图中使用filteredAndSortedRestaurants的地方**
```swift
// 将ForEach(filteredAndSortedRestaurants)改为
ForEach(sortedRestaurants)
```
