## 重新定义卡片样式规范计划

### 问题分析
用户要求重新定义卡片样式，包括卡片圆角、封面图圆角、卡片垂直间距，并确保图片内容不溢出容器。当前样式不符合用户要求，需要更新AppTheme中的定义。

### 解决方案
1. **修改卡片圆角**：将卡片圆角从26pt改为16pt
2. **统一封面图圆角**：使封面图圆角与卡片圆角一致（16pt）
3. **更新卡片垂直间距**：将卡片垂直间距从16pt改为20pt
4. **确保图片不溢出**：确保封面图使用.clipped()

### 具体修改步骤

#### 1. 修改AppTheme中的圆角定义
- 打开AppTheme.swift文件
- 将Radius.base从26pt改为16pt
- 确保封面图圆角使用AppTheme.Radius.base

#### 2. 修改卡片垂直间距
- 打开AppTheme.swift文件
- 修改Spacing.lg从16pt改为20pt
- 或添加新的垂直间距常量

#### 3. 更新卡片组件
- 打开LibraryView.swift文件
- 更新封面图的.cornerRadius()使用AppTheme.Radius.base
- 确保封面图有.clipped()修饰符

### 预期效果
- 卡片圆角：16pt
- 封面图圆角：16pt（与卡片圆角一致）
- 卡片垂直间距：20pt
- 图片内容不溢出容器

### 代码示例

**1. AppTheme.swift修改**
```swift
// 修改圆角
struct Radius {
    static let base: CGFloat = 16 // 从26pt改为16pt
    // 其他圆角定义
}

// 修改间距
struct Spacing {
    static let lg: CGFloat = 20 // 从16pt改为20pt
    // 其他间距定义
}
```

**2. LibraryView.swift修改**
```swift
// 封面图使用统一圆角
.frame(...) // 尺寸设置
.cornerRadius(AppTheme.Radius.base) // 使用卡片圆角
.clipped() // 确保内容不溢出
```

### 注意事项
- 确保所有使用Radius.base的地方都能适应新的16pt值
- 确保所有使用Spacing.lg的地方都能适应新的20pt值
- 检查是否有其他地方直接使用了旧的圆角或间距值，需要统一更新
