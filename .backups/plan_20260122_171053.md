# 在标题和搜索框之间添加城市选择器

## 实现思路
1. 在LibraryView中添加RestaurantListViewModel实例
2. 修改headerSection布局，在标题和搜索框之间插入城市选择器
3. 使用Menu实现城市选择功能，高度与搜索框保持一致
4. 绑定城市选择器到ViewModel的selectedCity属性
5. 确保城市选择器的样式与整体设计保持一致

## 实现步骤
1. **添加ViewModel实例**：在LibraryView中初始化RestaurantListViewModel，传入restaurants和userLocation
2. **修改headerSection布局**：调整HStack结构，在标题和搜索框之间添加城市选择器
3. **实现城市选择器**：使用Menu组件创建城市选择按钮，显示当前选中城市，点击展开选择菜单
4. **设置样式和尺寸**：确保城市选择器的高度与搜索框一致，使用相同的背景色、圆角和阴影效果
5. **绑定数据**：将城市选择器的选中值与ViewModel的selectedCity属性绑定
6. **添加城市列表**：使用RegionManager获取所有可用城市，供选择器使用

## 代码实现要点
1. 在LibraryView中添加ViewModel实例：
   ```swift
   @StateObject private var viewModel: RestaurantListViewModel
   
   // 在初始化时创建ViewModel
   init() {
       let restaurants: [Restaurant] = [] // 实际使用时从SwiftData查询获取
       let viewModel = RestaurantListViewModel(restaurants: restaurants, userLocation: nil)
       _viewModel = StateObject(wrappedValue: viewModel)
   }
   ```

2. 修改headerSection，在标题和搜索框之间添加城市选择器：
   ```swift
   HStack(spacing: AppTheme.Spacing.md) {
       // 1. 标题"吃啥呢"
       Text("吃啥呢")
           .font(AppTheme.Fonts.largeTitle)
           .fontWeight(.bold)
           .foregroundColor(AppTheme.Colors.textPrimary)
       
       // 2. 城市选择器
       Menu {
           ForEach(RegionManager.shared.allCities, id: \.self) {
               Button($0) { viewModel.selectedCity = $0 }
           }
       } label: {
           HStack {
               Text(viewModel.selectedCity)
                   .font(AppTheme.Fonts.body)
                   .foregroundColor(AppTheme.Colors.textPrimary)
               Image(systemName: "chevron.down")
                   .font(.caption)
                   .foregroundColor(.gray)
           }
           .padding(.horizontal, AppTheme.Spacing.md)
           .frame(height: 44) // 与搜索框高度一致
           .background(AppTheme.Colors.card)
           .cornerRadius(AppTheme.Radius.base)
       }
       
       // 3. 搜索框（占据剩余空间）
       // ... 现有搜索框代码 ...
   }
   ```

3. 确保城市选择器的样式与搜索框保持一致：
   - 使用相同的背景色：AppTheme.Colors.card
   - 相同的圆角：AppTheme.Radius.base
   - 相同的高度：通过padding和frame.height控制
   - 相同的字体：AppTheme.Fonts.body

4. 绑定城市选择器到ViewModel的selectedCity属性：
   - Menu的label显示当前选中城市：`Text(viewModel.selectedCity)`
   - 点击菜单选项时更新selectedCity：`Button($0) { viewModel.selectedCity = $0 }`

## 预期效果
- 城市选择器显示在标题和搜索框之间
- 城市选择器高度与搜索框一致
- 点击城市选择器展开城市列表
- 选中城市后，城市选择器显示选中的城市名称
- 城市选择器的样式与整体设计保持一致
- 城市选择器的选中值与ViewModel的selectedCity属性绑定，用于后续过滤餐厅列表
