# RestaurantCard 原位展开重构计划

## 目标
将详情页从"全屏覆盖"改为"列表内原位展开"，效果类似 App Store 活动卡片的展开方式。

## 实现方案

### 1. 新增展开内容组件 ExpandedRestaurantView

创建一个轻量级组件，只包含需要在展开后显示的额外内容：
- 统计卡片（收录时间、累计打卡、人均消费）
- 路线信息
- 打卡记录列表
- 底部操作栏

这些内容在收起状态时不显示，展开后平滑过渡显示。

### 2. 修改 RestaurantListView

- 在 LazyVStack 中，被点击卡片的下方条件渲染 ExpandedRestaurantView
- 使用 `@Binding var expandedRestaurantId: UUID?` 跟踪当前展开的卡片
- 展开时，卡片高度增加，ExpandedRestaurantView 内容平滑显示

### 3. 动画协调

- RestaurantCard 保持现有 matchedGeometryEffect
- ExpandedRestaurantView 中的组件使用相同的 ID 实现归位动效
- 展开高度使用 `.frame` 和 `.clipped` 配合动画

### 4. 布局结构

```
LibraryView
└── ZStack (背景)
    └── VStack
        ├── HeaderView
        ├── FilterBarView
        └── LazyVStack
            ├── RestaurantCard (收起状态)
            ├── RestaurantCard
            ├── RestaurantCard (展开状态)
            │   └── ExpandedRestaurantView ← 新增的展开内容
            └── RestaurantCard
```

### 5. 组件 ID 映射

| 组件 | 收起状态 ID | 展开状态 ID |
|------|-------------|-------------|
| 封面图 | coverImage-xxx | coverImage-xxx |
| 标题 | title-xxx | title-xxx |
| 统计卡片 | - | stats-xxx |
| 路线信息 | - | route-xxx |
| 打卡记录 | - | logs-xxx |
