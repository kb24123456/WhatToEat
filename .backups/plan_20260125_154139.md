# RestaurantDetailView 英雄动画重构计划

## 阶段一：LibraryView 转场架构调整

### 1.1 添加状态管理
- 添加 `@Namespace var animation` 用于共享动画命名空间
- 添加 `@State var selectedRestaurant: Restaurant?` 控制详情页显示
- 添加 `@State var isAnimating: Bool = false` 控制动画状态

### 1.2 重构列表视图
- 移除 `NavigationLink` 包装
- 改用 `onTapGesture { selectedRestaurant = restaurant }` 触发展开
- RestaurantCard 增加参数：`namespace: Namespace.ID`
- RestaurantCard 封面图应用 `.matchedGeometryEffect(id: "coverImage-\(restaurant.id)")`
- RestaurantCard 餐厅名称应用 `.matchedGeometryEffect(id: "title-\(restaurant.id)")`

### 1.3 ZStack 覆盖层
- 在 VStack 之后添加 `RestaurantDetailView` 覆盖层（使用 ZStack）
- 条件渲染：`if let restaurant = selectedRestaurant { RestaurantDetailView(...) }`
- 动画曲线：`.spring(response: 0.5, dampingFraction: 0.8)`

## 阶段二：RestaurantDetailView UI 重构

### 2.1 布局调整
- 移除导航栏，使用沉浸式设计
- 背景改为 `AppTheme.Colors.background`（米白色 #FBF9F7）
- 添加关闭按钮（xmark.circle.fill），点击时 `selectedRestaurant = nil`

### 2.2 Hero 区域（380pt）
- 封面图高度 380pt
- 应用 `.matchedGeometryEffect(id: "coverImage-\(restaurant.id)")`
- 圆角从列表状态过渡到 0（顶部忽略安全区域）
- `.ignoresSafeArea(edges: .top)`

### 2.3 卡片化信息模块
所有模块封装在圆角卡片中：
- 路线信息卡片
- 我的印象卡片
- 统计卡片（横向 HStack，增加图标装饰）
- 打卡记录列表（手账贴纸风格）

### 2.4 底部操作栏
- "我要打卡" 按钮改为底部悬浮固定
- 使用 `AppTheme.Colors.accent` 背景
- 样式参考 AddRestaurantView 保存按钮

---

## 阶段三：UI 规范统一

### 3.1 配色与背景
- 详情页背景：`Color(hex: "#FBF9F7")`
- 卡片背景：纯白
- 投影：`AppTheme.Shadows.light`

### 3.2 字体与间距
- 严格使用 `AppTheme.Fonts` 预设
- 模块间距：`AppTheme.Spacing.lg` (16pt)
- 卡片圆角：`AppTheme.Radius.base` (24pt)

### 3.3 打卡记录样式
- 移除 `Color(.systemGray6)`
- 改用奶油色系背景
- 保持手账贴纸风格

## 阶段四：功能迁移

### 4.1 保持不变的逻辑
- SwiftData 模型（Restaurant, VisitLog）
- locationManager 路线获取
- 打卡编辑/删除功能
- 封面图更换功能

### 4.2 需要调整的参数
- RestaurantDetailView 增加：`namespace: Namespace.ID`, `isPresented: Binding<Bool>`, `onDismiss: () -> Void`
- RestaurantCard 增加：`namespace: Namespace.ID`, `isExpanded: Bool`
