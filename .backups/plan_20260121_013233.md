## 问题分析
从崩溃信息和代码分析来看，应用在选择排序选项时崩溃，错误信息为：
"Could not find reflection metadata for typeno TypeInfo for field type (bound_generic_struct_SwiftData.SwiftUI_Query..."

这表明问题出在：
1. 当用户选择排序选项时，`handleSelection`方法被调用
2. 在该方法中，`activeSort`状态被更新
3. 状态更新触发了视图重新渲染
4. 视图重新渲染时，SwiftData尝试重新执行@Query，但遇到了反射元数据问题
5. 应用崩溃

## 解决方案

### 1. 修复SortOption枚举的rawValue转换
- 确保SortOption枚举能正确处理rawValue转换
- 优化handleSelection方法中排序选项的处理逻辑

### 2. 优化排序处理逻辑
- 避免直接使用rawValue转换来设置activeSort
- 改用更安全的方式来处理排序选项

### 3. 增强错误处理
- 在关键代码路径添加try-catch块
- 确保排序选项的更新不会导致应用崩溃

## 代码修改计划

### LibraryView.swift
```swift
// 修复handleSelection方法中的排序选项处理
private func handleSelection(_ item: String, for type: FilterType) {
    withAnimation {
        switch type {
        case .cuisine: selectedCuisine = (selectedCuisine == item) ? nil : item
        case .district: selectedDistrict = (selectedDistrict == item) ? nil : item
        case .sort:
            // 修复：使用更安全的方式来设置activeSort
            switch item {
            case "按评分": activeSort = .rating
            case "按距离": activeSort = .distance
            case "按名称": activeSort = .name
            default: activeSort = .default
            }
        case .city: selectedCity = (selectedCity == item) ? nil : item
        }
    }
    closeMenu()
}
```
