1. **分析当前字体设置**：

   * 当前地区、距离、评价使用固定的14pt字体：`Font.system(size: 14, design: .rounded)`
   * 这种设置在不同设备上尺寸固定，不会自动协调

2. **修改方案**：

   * 将固定14pt字体修改为使用`relativeTo`参数的动态字体
   * 使用`Font.system(size: 14, design: .rounded, relativeTo: .body)`
   * 这样既保持了14pt的基础大小，又能根据设备尺寸和用户偏好自动调整

3. **修改内容**：

   * 在`LibraryView.swift`文件中，修改`RestaurantCard`结构体的`body`部分
   * 将地区文本的字体从`Font.system(size: 14, design: .rounded)`改为`Font.system(size: 14, design: .rounded, relativeTo: .body)`
   * 将距离文本的字体从`Font.system(size: 14, design: .rounded)`改为`Font.system(size: 14, design: .rounded, relativeTo: .body)`
   * 将评价文本的字体从`Font.system(size: 14, design: .rounded)`改为`Font.system(size: 14, design: .rounded, relativeTo: .body)`

4. **预期效果**：

   * 地区、距离、评价字体在不同尺寸设备上自动协调
   * 保持相对一致的视觉比例
   * 响应用户的字体大小偏好设置
   * 符合iOS设计最佳实践
   * 代码编译成功

5. **验证步骤**：

   * 修改完成后，运行xcodebuild命令验证编译是否成功
   * 确保所有组件字体设置符合要求
