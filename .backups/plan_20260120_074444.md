# 重新定义UI元素水平最小间距

## 问题分析
1. 搜索框当前使用AppTheme.Spacing.lg (20pt)，需要改为16pt
2. 筛选按钮当前使用AppTheme.Spacing.lg (20pt)，需要改为16pt
3. 餐厅卡片当前使用AppTheme.Spacing.card (16pt)，已经符合要求
4. 导航栏按钮当前没有水平间距，需要添加16pt间距

## 解决方案
1. 修改搜索框的水平间距设置
2. 修改筛选按钮的水平间距设置
3. 为导航栏按钮添加水平间距
4. 保持餐厅卡片的间距不变

## 实现步骤
1. 修改LibraryView.swift中的searchBarSection，将.padding(.horizontal, AppTheme.Spacing.lg)改为.padding(.horizontal, AppTheme.Spacing.card)
2. 修改LibraryView.swift中的filterBarSection，将.padding(.horizontal, AppTheme.Spacing.lg)改为.padding(.horizontal, AppTheme.Spacing.card)
3. 修改ContentView.swift中的customTabBar，为HStack添加.horizontal, AppTheme.Spacing.card的padding
4. 运行项目验证效果，确保所有元素的水平最小间距都为16pt

## 预期效果
- 搜索框距离页面最小水平间距：16pt
- 筛选按钮距离页面最小水平间距：16pt
- 餐厅卡片距离页面最小水平间距：16pt（保持不变）
- 导航栏按钮距离导航条最小水平间距：16pt
- 所有元素的间距保持一致，视觉上更加统一

## 技术实现
1. 修改LibraryView.swift文件
2. 修改ContentView.swift文件
3. 保持AppTheme.Spacing的定义不变，因为card值已经是16pt
4. 确保编译通过
5. 验证修改效果
