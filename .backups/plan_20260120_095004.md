## 定义卡片尺寸实现完美适配的方案

### 问题分析
要让餐厅卡片在不同尺寸的iOS设备上完美显示，需要考虑以下因素：
- **设备尺寸多样性**：从iPhone SE到iPhone Pro Max，屏幕宽度和高度差异很大
- **内容完整性**：确保卡片内的所有信息（封面图、名称、标签、价格、距离、评论）都能完整显示
- **视觉比例协调**：保持封面图9:16比例，同时确保卡片整体比例协调
- **交互友好性**：卡片尺寸适中，便于点击和浏览

### 解决方案

#### 1. 采用响应式设计原则
- **卡片宽度**：自适应屏幕宽度，减去左右各16pt的最小间距
- **卡片高度**：基于内容动态计算，确保能容纳所有信息
- **封面图**：保持9:16比例，高度根据设备尺寸调整

#### 2. 具体实现方案

**（1）固定宽度+动态高度**
```swift
// 卡片宽度 = 屏幕宽度 - 32pt
// 封面图宽度 = 固定值100pt（适应所有设备）
// 封面图高度 = 100pt * (16/9) ≈ 178pt
// 卡片高度 = 封面图高度 + 内容间距
```

**（2）使用相对字体大小**
```swift
// 使用系统相对字体大小，自动适应动态类型
.font(AppTheme.Fonts.title3) // 标题
.font(AppTheme.Fonts.body)    // 正文
.font(AppTheme.Fonts.caption) // 辅助文字
```

**（3）灵活的内部布局**
```swift
// 使用VStack和HStack的组合
// 配合spacing和padding创建灵活布局
VStack(alignment: .leading, spacing: 8) {
    // 餐厅名称
    // 标签
    // 价格和距离
    // 评论
}
.padding(.vertical, 8)
```

**（4）使用GeometryReader获取屏幕尺寸**
```swift
GeometryReader { geometry in
    let screenWidth = geometry.size.width
    let cardWidth = screenWidth - 32 // 左右各16pt间距
    let coverWidth = cardWidth * 0.3 // 封面图宽度占卡片宽度的30%
    let coverHeight = coverWidth * (16/9) // 保持9:16比例
    
    // 卡片布局
    HStack(spacing: 12) {
        // 封面图
        // 信息区域
    }
    .frame(height: max(coverHeight, 180)) // 确保最小高度
}
```

### 最佳实践

#### 1. 优先使用固定尺寸的封面图
- **方案**：封面图宽度固定为100pt，高度固定为178pt（9:16比例）
- **优点**：在所有设备上保持一致的视觉效果，便于设计和测试
- **缺点**：在大屏设备上可能显得较小

#### 2. 基于设备宽度的比例计算
- **方案**：封面图宽度 = 屏幕宽度 * 0.3，高度 = 封面图宽度 * (16/9)
- **优点**：在不同设备上保持相对一致的视觉比例
- **缺点**：需要动态计算，可能在某些设备上出现布局问题

#### 3. 使用大小类适配
- **方案**：根据设备的sizeClass（compact/regular）调整布局
```swift
@Environment(\.horizontalSizeClass) private var horizontalSizeClass

var coverWidth: CGFloat {
    horizontalSizeClass == .compact ? 100 : 150
}
```

### 推荐实现

综合考虑，推荐使用以下方案：

**1. 卡片宽度**：自适应屏幕宽度，减去左右各16pt间距
**2. 封面图**：固定100pt宽度，178pt高度（9:16比例）
**3. 卡片高度**：固定为178pt（与封面图高度一致）
**4. 内部布局**：使用VStack和HStack配合spacing，确保内容合理排列
**5. 字体**：使用相对字体大小，支持动态类型
**6. 间距**：使用AppTheme.Spacing系统，保持一致的间距

### 代码示例

```swift
struct RestaurantCard: View {
    // 封面图尺寸：固定100x178pt（9:16比例）
    private let coverSize = CGSize(width: 100, height: 178)
    
    var body: some View {
        NavigationLink(destination: RestaurantDetailView(...)) {
            HStack(alignment: .top, spacing: AppTheme.Spacing.md) {
                // 封面图
                Group {
                    // 封面图实现
                }
                .frame(width: coverSize.width, height: coverSize.height)
                .cornerRadius(12)
                .clipped()
                
                // 信息区域
                VStack(alignment: .leading, spacing: 6) {
                    // 餐厅名称
                    // 标签
                    // 价格和距离
                    // 评论
                }
                .frame(maxWidth: .infinity, alignment: .leading)
                .padding(.vertical, AppTheme.Spacing.sm)
            }
            .background(AppTheme.Colors.card)
            .cornerRadius(AppTheme.Radius.base)
            .padding(.horizontal, AppTheme.Spacing.lg)
        }
    }
}
```

### 注意事项
- 避免过度使用GeometryReader，可能导致布局复杂化
- 优先使用固定尺寸+自适应布局，减少动态计算
- 测试不同设备尺寸，特别是iPhone SE和iPhone Pro Max
- 确保内容不会被截断，使用.lineLimit(nil)或合理的lineLimit
- 考虑动态类型，使用相对字体大小
- 保持一致的设计语言，使用设计系统定义的颜色、间距和字体

### 验证方法
1. 使用Xcode的Preview功能测试不同设备尺寸
2. 在模拟器中运行，测试iPhone SE、iPhone 15、iPhone 15 Pro Max
3. 测试不同的动态类型大小
4. 检查内容是否完整显示，无截断
5. 确保交互友好，卡片易于点击
